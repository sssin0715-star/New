# 신규입사자 면담 예약

신규입사자가 링크 하나로 면담 시간을 직접 고르는 예약 페이지입니다. 예약 내역은 구글 스프레드시트에 쌓이고, 담당자는 같은 페이지에서 관리자 코드로 현황을 확인합니다.

- **화면** — GitHub Pages (정적)
- **저장** — Google Apps Script + 스프레드시트

방문자에게는 "어느 시간이 찼는지"만 내려갑니다. 예약자 이름·이메일·연락처는 관리자 코드를 확인한 뒤에만 서버가 내려주므로, 이 저장소 어디에도 개인정보가 들어 있지 않습니다.

---

## 구성

```
docs/index.html     예약 화면 (GitHub Pages가 이 폴더를 서비스합니다)
apps-script/Code.gs 서버 — 예약 저장, 중복 방지, 관리자 인증, 메일 발송
```

`docs/index.html` 한 파일이 두 환경에서 모두 동작합니다. GitHub Pages에 올리면 `API_BASE` 주소를 JSONP로 호출하고, 앱스스크립트 안에 붙여넣으면 `google.script.run`을 그대로 씁니다.

---

## 설치

### 1단계 — 스프레드시트와 스크립트

1. [sheets.new](https://sheets.new) 로 새 스프레드시트를 만들고 이름을 정합니다
2. **확장 프로그램 → Apps Script**
3. 기본 `Code.gs` 내용을 지우고 이 저장소의 `apps-script/Code.gs` 를 붙여넣습니다
4. 왼쪽 **파일 +** → **HTML** → 이름 `Index` → 이 저장소의 `docs/index.html` 을 붙여넣습니다
5. 저장

> 4단계는 앱스스크립트 주소로도 페이지를 열고 싶을 때만 필요합니다. GitHub Pages만 쓸 거라면 건너뛰어도 예약은 정상 동작합니다.

### 2단계 — 웹앱 배포

6. **배포 → 새 배포 → 웹 앱**

   | 항목 | 값 |
   |---|---|
   | 다음 사용자 인증 정보로 실행 | **나** |
   | 액세스 권한이 있는 사용자 | **모든 사용자** |

7. 권한 승인 → `Google에서 확인하지 않은 앱입니다` 화면이 나오면 **고급 → (안전하지 않음) 이동 → 허용**
8. 나온 **웹 앱 URL**(`/exec` 로 끝나는 주소)을 복사합니다

### 3단계 — 화면에 서버 주소 연결

9. `docs/index.html` 위쪽에서 이 줄을 찾아 8단계 주소를 넣습니다

   ```js
   var API_BASE = "";
   ```

10. 커밋하고 푸시합니다

### 4단계 — GitHub Pages 켜기

11. 저장소 **Settings → Pages**
12. **Source: Deploy from a branch**, **Branch: `main` / `docs`** 선택 후 저장
13. 1~2분 뒤 `https://<사용자명>.github.io/<저장소명>/` 이 열립니다

### 5단계 — 관리자 코드

14. 스프레드시트로 돌아가 새로고침 → 상단 **면담 예약 → 초기 설정 / 관리자 코드 확인**
15. 나오는 8자리 코드를 적어둡니다

---

## 주소 정리

| 용도 | 주소 |
|---|---|
| 신규입사자 배포용 | `https://<사용자명>.github.io/<저장소명>/` |
| 담당자 관리 화면 | 같은 주소 → 페이지 맨 아래 **담당자** → 관리자 코드 입력 |

관리자 코드는 서버에서 확인합니다. 코드를 모르면 예약자 명단이 내려오지 않습니다.

---

## 알아두실 점

- **스크립트를 고치면 다시 배포해야 합니다.** `배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포`. URL은 그대로 유지됩니다. `새 배포`를 누르면 주소가 새로 생기니 주의하세요.
- **메일**은 배포한 구글 계정 명의로 나갑니다. 일반 지메일은 하루 100통, 워크스페이스는 1,500통 한도입니다. 관리 화면에서 끌 수 있습니다.
- **동시 예약**은 서버에서 `LockService` 로 잠금을 걸어 처리하므로, 두 명이 같은 시간을 동시에 눌러도 한 명만 확정됩니다.
- **설정 변경**은 관리 화면에서도, `설정` 시트에서 직접 값을 고쳐도 됩니다.
- 예약 현황은 25초마다, 그리고 탭으로 돌아올 때마다 갱신됩니다.
- 웹 앱을 **모든 사용자** 로 배포하면 주소를 아는 누구나 예약할 수 있습니다. 사내에서만 쓰실 거면 링크 공유 범위를 관리해주세요.
