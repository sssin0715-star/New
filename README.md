# 신규입사자 면담 예약

신규입사자가 링크 하나로 면담 시간을 직접 고르는 예약 페이지입니다. 의존성 없는 Node.js 서버 하나로 화면과 API를 모두 서비스합니다.

- 실시간 마감 — 다른 사람이 예약하면 열려 있는 화면에서도 곧 회색으로 바뀝니다
- 중복 예약 방지 — 확인과 기록을 한 묶음으로 처리해 같은 시간에 두 명이 눌러도 한 명만 확정됩니다
- 본인 취소 — 예약자가 담당자를 거치지 않고 직접 취소할 수 있습니다
- 담당자 화면 — 기간·요일·시간 설정, 개별 마감, 명단 확인, CSV 내려받기

방문자에게는 "어느 시간이 찼는지"만 내려갑니다. 이름·이메일·연락처는 서버가 관리자 코드를 확인한 뒤에만 보냅니다.

---

## 구성

```
server.js           HTTP 서버 — 정적 파일 + /api/*  (외부 패키지 0개)
public/index.html   예약 화면
data/store.json     예약 데이터 (실행 중 자동 생성, git에 올리지 않음)
```

`npm install` 이 필요 없습니다. Node 18 이상이면 바로 실행됩니다.

## 실행

```bash
node server.js
```

`http://localhost:3000` 에서 열립니다. 첫 실행 때 관리자 코드가 터미널에 찍히고 `data/store.json` 에 저장됩니다.

### 환경 변수

| 이름 | 기본값 | 설명 |
|---|---|---|
| `PORT` | `3000` | 포트 |
| `ADMIN_CODE` | 자동 생성 | 관리자 코드. 처음 실행 전에 지정하면 그 값을 씁니다 |
| `DATA_DIR` | `./data` | 저장 폴더. **호스팅의 영구 디스크를 여기로 잡으세요** |

## 사용

| 용도 | 방법 |
|---|---|
| 신규입사자 | 배포된 주소를 그대로 안내 |
| 담당자 | 같은 주소 → 페이지 맨 아래 **담당자** → 관리자 코드 입력 |

관리자 코드는 서버에서 검증합니다. 코드를 모르면 명단이 내려오지 않습니다.

---

## 배포할 때 꼭 확인할 것

**예약 데이터는 `DATA_DIR` 아래 파일에 저장됩니다.** 무료 호스팅 상당수는 재시작할 때 디스크가 초기화되므로, 그대로 쓰면 예약이 사라집니다. 반드시 아래 중 하나로 하세요.

- 영구 디스크(볼륨)를 붙이고 `DATA_DIR` 을 그 경로로 지정
- 또는 담당자가 CSV를 자주 내려받아 보관

`ADMIN_CODE` 는 호스팅의 환경 변수로 넣으세요. 저장소에는 코드도 예약 데이터도 들어 있지 않습니다.

배포한 주소를 아는 누구나 예약할 수 있습니다. 사내에서만 쓰신다면 링크 공유 범위를 관리하거나, 접근 제한이 되는 곳에 올려주세요.
