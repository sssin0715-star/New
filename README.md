# 신규입사자 면담 예약

신규입사자가 링크 하나로 면담 시간을 직접 고르는 예약 페이지입니다.

- 실시간 마감 — 다른 사람이 예약하면 열려 있는 화면에서도 곧 회색으로 바뀝니다
- 중복 예약 방지 — 같은 시간에 두 명이 눌러도 한 명만 확정됩니다
- 본인 취소 — 예약자가 담당자를 거치지 않고 직접 취소할 수 있습니다
- 담당자 화면 — 기간·요일·시간 설정, 개별 마감, 명단 확인

방문자에게는 "어느 시간이 찼는지"만 내려갑니다. 이름·이메일·연락처는 서버가 관리자 코드를 확인한 뒤에만 보냅니다.

화면은 두 방식 모두 **동일합니다.** 예약을 어디에 저장하느냐만 다릅니다.

---

## 방식 1 — 구글 앱스스크립트 (권장)

구글 계정만 있으면 됩니다. 설치도, 새 가입도, 비용도 없습니다. 예약은 스프레드시트에 쌓입니다.

```
apps-script/Code.gs      서버 — 예약 저장, 중복 방지, 관리자 인증, 확인 메일
apps-script/Index.html   예약 화면
```

1. [sheets.new](https://sheets.new) 로 스프레드시트를 만듭니다
2. **확장 프로그램 → Apps Script**
3. 기본 `Code.gs` 를 지우고 `apps-script/Code.gs` 를 붙여넣습니다
4. **파일 +** → **HTML** → 이름 `Index` → `apps-script/Index.html` 을 붙여넣습니다
5. **배포 → 새 배포 → 웹 앱**

   | 항목 | 값 |
   |---|---|
   | 다음 사용자 인증 정보로 실행 | **나** |
   | 액세스 권한이 있는 사용자 | **모든 사용자** |

6. 권한 승인 → `Google에서 확인하지 않은 앱입니다` 가 나오면 **고급 → (안전하지 않음) 이동 → 허용**
7. 나온 **웹 앱 URL** 이 배포 주소입니다
8. 스프레드시트로 돌아가 새로고침 → **면담 예약 → 초기 설정** 에서 관리자 코드를 확인합니다

> 코드를 고친 뒤에는 `배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포`. URL 은 그대로 유지됩니다. `새 배포` 를 누르면 주소가 새로 생기니 주의하세요.

## 방식 2 — Node.js 서버

서버를 직접 운영할 수 있을 때 씁니다. 외부 패키지가 하나도 없어서 `npm install` 이 필요 없습니다.

```
server.js           HTTP 서버 — 정적 파일 + /api/*
public/index.html   예약 화면
data/store.json     예약 데이터 (실행 중 자동 생성, git 에 올리지 않음)
```

```bash
node server.js
```

| 환경 변수 | 기본값 | 설명 |
|---|---|---|
| `PORT` | `3000` | 포트 |
| `ADMIN_CODE` | 자동 생성 | 관리자 코드 |
| `DATA_DIR` | `./data` | 저장 폴더. **영구 디스크를 여기로 잡으세요** |

무료 호스팅 상당수는 재시작할 때 디스크가 초기화됩니다. 그대로 쓰면 예약이 사라지니, 영구 디스크(볼륨)를 붙이고 `DATA_DIR` 을 그 경로로 지정하세요.

---

## 사용

| 용도 | 방법 |
|---|---|
| 신규입사자 | 배포된 주소를 그대로 안내 |
| 담당자 | 같은 주소 → 페이지 맨 아래 **담당자** → 관리자 코드 입력 |

관리자 코드는 서버에서 검증합니다. 코드를 모르면 명단이 내려오지 않습니다. 저장소에는 관리자 코드도 예약 데이터도 들어 있지 않습니다.

주소를 아는 누구나 예약할 수 있습니다. 사내에서만 쓰신다면 링크 공유 범위를 관리해주세요.
